# MuscleForge

Mobile-first, offline-capable muscle-building tracking web app.

## Features
- Today dashboard and daily habit checklist
- Four-day sample hypertrophy training split and workout log
- Estimated nutrition targets, sample meals and protein tracking
- Weight and body measurement tracking
- Editable profile and on-device backup export/import
- Progressive Web App installation using HTTPS hosting

## Deploy via GitHub Pages
1. In **Settings > Pages**, choose **Deploy from a branch**, `main`, `/ (root)` and Save.
2. Open https://mkassab2015.github.io/MuscleForge/.
3. On iPhone, Safari > Share > Add to Home Screen. On Android, Chrome > Install app.

**Privacy:** Data is stored on the device in its browser, not uploaded to GitHub or synced between devices. Export backups regularly.

**Health:** Guidance is approximate and should be tailored to your health and training history.
